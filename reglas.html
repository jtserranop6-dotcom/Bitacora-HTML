Reglas

1. Responsabilidad Única (SRP)

Cada fila documenta un solo evento, tarea o impedimento indivisible. Si realizó tres actividades en el día, registre tres filas independientes.

2. Cero Adjetivos Subjetivos

Prohibido escribir "estuvo chévere", "fue difícil", "avanzamos bien". Redacte únicamente los hechos técnicos verificables.

3. Inmutabilidad

Si un registro histórico contiene un error o cambio, no lo borre ni sobrescriba. Cree un nuevo registro con fecha actual indicando: "Corrección/Ajuste al registro ID [X]".

4. Impedimentos

Si no presentó dificultades, escriba expresamente: "Sin impedimentos operativos".

GUÍA DE LLENADO POR COLUMNA

ID

Número consecutivo único para cada actividad o fila (ej. 001 002).

Timestamp (YYYY-MM-DD HH:MM)

Fecha y hora exacta en la que se registra o ejecuta la actividad (formato AAAA-MM-DD HH:MM).

Autoría (Responsable)

Nombre o iniciales del aprendiz responsable de ejecutar la actividad.

Objeto Técnico (Actividad y Alcance)

Descripción técnica objetiva verificable y concreta de lo ejecutado y su alcance real.

Evidencia de Ejecución (Entregable / Enlace)

URL del commit enlace al Pull Request captura de pantalla o documento entregable.

Impedimentos / Blockers (Qué ejecutó qué falló qué esperaba)

Descripción técnica del error o impedimento. Si no hubo problemas escribir: "Sin impedimentos operativos".

Plan de Acción (Mitigación / Próxima Tarea)

Acción correctiva tomada próxima tarea programada o paso para desbloquear la actividad.
